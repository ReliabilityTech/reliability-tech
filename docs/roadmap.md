## Dívidas técnicas conhecidas

Registradas aqui de forma consciente, não esquecidas:

| Item | Onde | Por que existe |
| ---- | ---- | -------------- |
| RLS não cobre as tabelas "filhas" sem `tenant_id` próprio (`notas`, `presencas`, `turma_disciplinas`, `aluno_responsaveis`, `movimentacoes`, `ocorrencias`, `recado_anexos`, `recado_confirmacoes_leitura`, `mensagens`, `terceiros_autorizados`) nem `users`/`audit_logs` | banco (ver ADR 0006, roadmap 6.2) | As 8 tabelas com `tenant_id` direto já têm RLS; as filhas precisariam de política via join (mais lenta, mais fácil de errar) e `users`/`audit_logs` têm exceções legítimas (login, ações de super-admin) — mesma receita da 6.2 aplicável depois |
| Sem cache remoto do Turborepo | `turbo.json` | Só compensa com o time maior; hoje o cache é local |
| Imagem Docker da API inclui devDependencies (~1.08GB) | `apps/api/Dockerfile` | `pnpm prune --prod` corrompe os symlinks do pnpm contra o lockfile reduzido pelo `turbo prune` — corrigir isso é otimização de tamanho, não bug funcional |
